# HUMAN Decision — SPEC-017 canonical Production domain required

**Decision date:** 2026-09-15

**Decision:** SUPERSEDED BEFORE FINAL G2A ACCEPTANCE

**Historical requirement:** PAID/CUSTOM DOMAIN BEFORE LAUNCH · SUPERSEDED

This intermediate decision treated acquisition of a paid/custom domain as required before launch. The HUMAN subsequently corrected that interpretation before final G2A acceptance: custom-domain absence is not an MVP blocker, and the exact official Vercel Production `*.vercel.app` hostname may serve as the initial canonical Production origin.

This superseded record is preserved only for decision history and must not be used as an active launch requirement.

No domain purchase, DNS change, provider mutation, deployment, HSTS activation, or public launch is authorized.
